## Setup
Create venv using `python3 -m venv venv` (or `python -m venv venv` for Windows).

Activate venv using `source venv/bin/activate` (or `./venv/Scripts/Activate.ps1` for powershell).

Run `pip install -r requirements.txt` to install dependancies.

Then `python extrinsic_calibration --help` for instructions on running .py file.
