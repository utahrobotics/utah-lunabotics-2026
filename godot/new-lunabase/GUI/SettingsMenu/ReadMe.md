# Why?
Things are getting cluttered. I want to have a simple settings menu that can toggle different GUIs to declutter the screen. It can also help with having a localized place to have scene navigation or other tools in the future

# How it works
This is a global scene. You can add buttons or signals that other scripts can connect to.
